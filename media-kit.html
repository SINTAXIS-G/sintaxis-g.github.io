Larga (para nota o entrevista)

Gabriel Adolfo Merino Hernández, conocido como Gabo, es un arquitecto de software independiente de 28 años. Construye software de principio a fin — diseña la arquitectura, desarrolla los sistemas que la componen y las herramientas que los mantienen funcionando — bajo el nombre SINTAXIS G. Su proyecto insignia es ARCHANGEL: un motor de análisis estático que corre 71 analizadores especializados sobre código Python (200.000+ líneas propias), correlacionando sus señales con un motor bayesiano en vez de devolver una lista plana de warnings. Su particularidad es tratar el código como un sistema físico real: entropía de Shannon para medir desorden léxico, el criterio de fractura de Griffith para predecir colapsos estructurales, y el límite de Chandrasekhar para detectar archivos que acumularon demasiada masa cognitiva. Otro proyecto del ecosistema, EIDOLON, es un motor de simulación cognitiva 100% local que incluye un auditor de consistencia narrativa (Canon Auditor) construido sin embeddings ni modelos de ML — tres capas de reglas lingüísticas (negación, polaridad opuesta, conflicto de atributos) que detectan cuándo una respuesta de IA contradice un hecho ya establecido, aunque comparta la mayoría de las palabras con él. Su stack de trabajo principal es Python (AST, multiprocessing, Z3, criptografía) y JavaScript sin framework cuando el control fino sobre el navegador importa. Su lema: "No instalo sistemas. Forjo arquitecturas."
